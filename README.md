# Obstacle Detection Robot Car

## Project Description

Our project focuses on building an autonomous robot car that uses sensors to detect obstacles and avoid collisions. The car will navigate around objects in its path and move independently. If possible, we will use a LiDAR sensor instead of an ultrasonic sensor to improve its obstacle detection ability and help it understand its surroundings better.
